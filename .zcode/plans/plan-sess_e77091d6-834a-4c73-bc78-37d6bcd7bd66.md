# UI Redesign: Dark, Editorial, Grid-based

## Goal
Restyle the site to match the reference aesthetic: **dark-first** (deep background, light text, toggle preserved), **serif headlines + sans body** (editorial), **grid-based layouts**, **colored semantic tags**, and a new **Topics** section with tag index + per-tag pages.

## Design system changes

### `global.css` — new theme tokens
- Go **dark-first**: redefine `@custom-variant dark` to mean "light mode" (so `dark:` now targets light, and bare classes are dark). This is the cleanest way — every component keeps using `dark:` prefixes, they just now style the *light* theme instead. The toggle still flips `<html>` class.
- Add **`--font-serif`** (Fraunces — a contemporary editorial serif with good display weights) to `@theme`, alongside the existing Inter sans and JetBrains Mono.
- Fix the latent `brand-950` bug (used in `index.astro` but undefined) by adding `--color-brand-950: #1e1b4b`.
- Keep the indigo brand ramp; it reads well on dark.

### `Base.astro` — dark-first body + serif font load
- Body classes flip to dark defaults: `bg-zinc-950 text-zinc-300` (bare), with `dark:bg-white dark:text-zinc-700` overrides (where `dark` now = light).
- Add Fraunces to the Google Fonts `<link>` (headlines 500/600/700).
- Add a `font-serif` utility expectation (Tailwind v4 generates it from the `--font-serif` token).

## Component-by-component changes

### `Header.astro`
- Restyle for dark-first: `bg-zinc-950/80` bare, `dark:bg-white/80` override; border `border-zinc-800/70` bare.
- Add **"Topics"** to the nav links array (→ `/tags`). Links: Blog, Topics, About.
- Headline logo stays (favicon + "The Inkpens." with brand period) but uses serif for the wordmark to match the editorial tone.

### `Footer.astro`
- Flip dark-first border/bg classes. Otherwise unchanged.

### `ThemeToggle.astro`
- Invert the FOUC script: default to dark (add `.dark` only when light is explicitly chosen). The two SVGs swap which is visible by default.

### `EssayCard.astro` — grid card + colored tags
- Restyle from a borderless list row to a **card** with a subtle border (`border border-zinc-800 dark:border-zinc-200`), padding, rounded corners, hover state (border brightens to brand).
- **Colored semantic tags**: replace the single neutral pill class with a lookup. A new `src/lib/tags.ts` exports a `tagStyle(tag)` function returning Tailwind classes from a fixed tag→color map (e.g. `gpu` → emerald, `posse` → indigo, `automation` → sky, `embeddings` → violet, `systems` → amber, `fp8` → rose). Unknown tags fall back to zinc. Used in both EssayCard and Essay.

### `Essay.astro`
- Flip dark-first (border, prose invert direction). Prose container keeps `max-w-none` but the article column may widen slightly.
- Tags use the same `tagStyle()` colored pills.

## Trade-offs / notes
- **Dark-first via inverted variant** is the lowest-effort path (components keep their `dark:` prefixes) but it's a mental inversion — `dark:` now means light. I'll add a comment in `global.css` explaining it. The alternative (rewriting every class bare-first) is far more churn for the same result.
- **Fraunces** is a strong editorial serif with optical sizing; if you'd prefer something more neutral (Newsreader, Source Serif 4) it's a one-line font-swap. I'll use Fraunces as the default.
- **Tag→color map is hardcoded** in `tags.ts`. New tags get zinc (neutral). To color a new tag you add one line. This avoids schema changes and is the pragmatic choice for a small tag set.
- **Grid on the blog list** trades scanability for visual richness. The reference is grid-based, so this matches — but if you prefer the divided-list for the full blog index, I can keep that as a list and only grid the homepage "latest."
