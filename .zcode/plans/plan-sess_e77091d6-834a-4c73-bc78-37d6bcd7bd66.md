## File 1 — NEW `site/scripts/lib/markdown.mjs` addition: `markdownToHtml()`

Add a second export alongside the existing `mdxToMarkdown`:

```js
import remarkRehype from 'remark-rehype';
import rehypeStringify from 'rehype-stringify';
import remarkGfm from 'remark-gfm';

export async function markdownToHtml(markdown) {
  const output = await unified()
    .use(remarkParse)
    .use(remarkMath)
    .use(remarkGfm) // tables
    .use(remarkRehype, { allowDangerousHtml: false })
    .use(rehypeStringify)
    .process(markdown);
  return String(output);
}
```

**Why not run math through `rehype-katex`:** Medium/Substack don't load KaTeX CSS, so KaTeX HTML would render as broken markup. Leave math as plain `$…$` text. (No essay has math today anyway.)

Design choice: `markdownToHtml` takes sanitized markdown (the output of `mdxToMarkdown`) as input, so all the JSX-stripping / screenshot-inlining / import-removal logic is reused unchanged. The orchestrator calls `mdxToMarkdown` first, then `markdownToHtml` on the result.

## File 2 — `site/scripts/lib/manual-package.mjs`: add `packageHtmlPath()` + `writeHtmlPackage()`

Two new exports:

- **`packageHtmlPath(slug)`** → `join(OUT_DIR, 'syndicate-${slug}.html')` (sibling of the .md file)
- **`writeHtmlPackage({ slug, title, bodyHtml, canonicalUrl })`** → writes a self-contained HTML document (inline `<style>` for sane defaults: max-width, serif body, monospace code, table borders) with the body HTML inside `<article>`. **Overwrites unconditionally** each run (HTML is fully derived from the essay, no platform notes to dedup — idempotent by nature).

The HTML doc is deliberately minimal so it pastes cleanly into rich-text editors:

```html
<!doctype html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>{title}</title>
    <style>
      body {
        max-width: 720px;
        margin: 2rem auto;
        font-family: serif;
        line-height: 1.6;
      }
      code,
      pre {
        font-family: monospace;
      }
      pre {
        background: #f4f4f4;
        padding: 1rem;
        overflow-x: auto;
      }
      table {
        border-collapse: collapse;
      }
      td,
      th {
        border: 1px solid #ccc;
        padding: 0.4rem 0.8rem;
      }
      img {
        max-width: 100%;
      }
    </style>
  </head>
  <body>
    <article>{bodyHtml}</article>
  </body>
</html>
```

  desc: 'Open the latest manual package HTML + Medium/Substack editor tabs (internal)'
