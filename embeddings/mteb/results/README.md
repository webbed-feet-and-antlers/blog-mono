# Embedding evaluation results

This directory is **committed to git** — every per-model JSON and the
`_leaderboard.md` table are intended to live in PR diffs so model comparisons
are reviewable.

## Layout

```
results/
├── README.md                          # this file
├── _leaderboard.md                    # regenerated on every run (comparison table)
├── openai_text-embedding-3-small.json
├── openai_text-embedding-3-large.json
├── gemini_text-embedding-004.json
├── gemini_gemini-embedding-001.json
├── st_all-MiniLM-L6-v2.json           # sentence-transformers models get an `st_` prefix
└── st_bge-base-en-v1.5.json
```

The `st_` prefix is historical shorthand — the JSON `provider` field inside
each file is `sentence-transformers` (not `st`).

## Per-model JSON schema

```json
{
  "model": "openai/text-embedding-3-small",
  "provider": "openai",
  "run_at": "2026-07-18T19:30:00Z",
  "git_sha": "abc1234",
  "task_results": [
    {
      "task": "govreport_retrieval",
      "metric": "ndcg@10",
      "score": 0.612,
      "n_examples": 300,
      "runtime_seconds": 14.3
    },
    {
      "task": "govreport_sts",
      "metric": "spearman",
      "score": 0.731,
      "n_examples": 300,
      "runtime_seconds": 2.1
    }
  ]
}
```

Each entry in `task_results` corresponds to one (task, metric) pair. Tasks
that emit more than one metric (e.g. retrieval emits NDCG@10 + MAP@10) appear
as multiple entries sharing the same `task` field.

## Leaderboard columns

`_leaderboard.md` is regenerated by `evaluate/results.py:regenerate_leaderboard`
on every run. The columns (one per task family) are:

| Column | Task | Metric |
|---|---|---|
| Retrieval (NDCG@10) | `govreport_retrieval` | `ndcg@10` |
| Cross-Report (NDCG@10) | `govreport_cross_report` | `ndcg@10` |
| STS (Spearman) | `govreport_sts` | `spearman` |
| Summary STS (Spearman) | `govreport_summary_sts` | `spearman` |
| Clustering (V-measure) | `govreport_clustering` | `v_measure` |
| Reranking (MAP@10) | `govreport_reranking` | `map@10` |
| Pair Class. (ROC-AUC) | `govreport_pair_classification` | `roc_auc` |

Missing cells (—) indicate the task was skipped (e.g. dataset absent) or not
run for that model.

## Regenerating

```bash
# Re-run a single model — overwrites its JSON, regenerates the leaderboard.
python3 mteb/evaluate/__main__.py \
    --provider openai --model text-embedding-3-small

# Full matrix:
task mteb:evaluate:all
```

Per-model JSON files are **overwritten** on each run (single source of truth).
The leaderboard is fully regenerated from scratch each time.

## Out of scope

- Historical trend tracking. Each run replaces prior numbers. If you need
  history, compare via git log on the per-model JSON.
- Aggregated composite scores. We report raw per-metric numbers only; ranking
  by average is left to the reader.
